This Week 1 submission presents a complete data-cleaning and preliminary exploratory analysis workflow using R. The selected dataset is the public `airquality` dataset from R's built-in `datasets` package, containing 153 daily air-quality observations from New York covering May to September 1973. The dataset was selected because it contains both continuous numerical measurements and a time-related categorical variable after appropriate transformation, as well as genuine missing values in Ozone and Solar.R.

The analysis begins with data loading, structure inspection, summary statistics, variable-type preparation, and a systematic missing-value audit. Missing Ozone and Solar.R observations are handled using month-specific median imputation so that the cleaning method respects the seasonal structure of the data rather than applying one global replacement value. Month is converted into a factor for categorical analysis, and one-hot encoding is demonstrated with R's model.matrix() function.

The preliminary analysis includes descriptive statistics for Ozone, Solar Radiation, Wind, and Temperature; IQR-based outlier detection; z-score normalization; correlation analysis; and month-level summaries. Visual evidence is provided through missing-value, distribution, boxplot, scatterplot, and correlation visualizations.

The main preliminary findings show that Ozone has a positive relationship with Temperature and a negative relationship with Wind. The cleaned dataset contains 153 complete observations for the main analysis variables. The IQR procedure identifies a small number of statistical outliers, which are flagged for investigation rather than automatically deleted because extreme environmental observations can be meaningful.

All important steps are documented in the accompanying R script so that the analysis can be reproduced in R/RStudio. The report includes methodology, rationale, results, limitations, and recommendations for the next stage of the internship, where the cleaned dataset can be extended into richer visualizations and insight communication.
