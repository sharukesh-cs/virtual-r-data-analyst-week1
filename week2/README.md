# Virtual R Data Analyst Internship - Week 2

This project focuses on creating informative visualizations using R to identify trends, patterns, relationships, and insights from the airquality dataset.

### Tools Used
- R
- ggplot2
- dplyr
- Data visualization techniques

To analyze the cleaned airquality dataset and communicate important findings through clear and meaningful visualizations.
